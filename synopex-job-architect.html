Step 3

레벨 · 문서 종류

레벨은 숙련수준입니다. 회사 직급·직책과 자동으로 동일시하지 않으며, NCS 수준도 참고 범위로만 표시합니다.

직무기술서는 수행 내용과 기준, 직무명세서는 요구 자격과 역량을 담습니다.
Step 4

표준 Template

사내 확인 필요표시는 공개자료로 확정할 수 없어 사내 확인이 필요한 칸입니다.
Step 5

직무별 교육체계

직무를 선택하면 해당 직무에 배정되는 교육과정과 레벨별 로드맵이 생성됩니다.

Step 6

교육 · 자격 이력관리

직원 데이터는 가상 예시 입니다. 실제 인사·교육 이력으로 교체하면 동일한 화면과 계산식이 그대로 적용됩니다.

Step 7

교육 배정 규칙

필수교육은 직급 하나로 결정하지 않습니다. 아래 8개 입력을 모두 보고 규칙에 따라 배정하며, 규칙에는 버전과 적용일을 둡니다.

R-03겸직 · 복수 직무두 직무의 필수 과정을 합집합으로 산출하고 과정 ID 기준으로 중복을 제거한다. 연간 교육시간 상한을 넘으면 기한을 분기 단위로 분산한다.직무별 기한 중 빠른 날짜상위 직무 수료분 공통 인정HRD 담당 + 양측 팀장
R-04승진 · 직책 변경직책·리더십 과정을 발령일 기준으로 배정한다. 숙련수준 상승은 실무평가 통과 시점에 상위 레벨 과정을 배정한다.발령일+90일직책 교육은 재이수 대상 아님HRD 담당
R-05선수조건 미충족후속 과정을 즉시 배정하지 않고 대기 상태로 둔다. 선수 과정 수료가 확인되면 자동으로 배정 상태로 전환한다.선수 수료일+90일—자동
R-06대체 · 동등과정사전 등록된 동등과정 수료는 인정한다. 외부 자격 취득은 해당 과정 면제로 처리하되 자격 유효기간을 따른다.원 과정 기한 승계동등과정 목록에 등록된 건만과정 담당자
R-07기존 수료 인정과정별 인정기간 내 수료만 인정한다. 인정기간이 지난 수료는 재이수 대상으로 전환한다.재이수는 전환일+90일인정기간 경과분 불인정자동
R-08중복 배정 방지(직원, 과정 ID, 유효 배정) 조합에 유일 제약을 둔다. 유효 배정이 이미 있으면 새 배정을 생성하지 않는다.기존 기한 유지—자동
R-09면제승인권자 승인 + 사유 + 증빙이 모두 있어야 한다. 면제 건은 분모에서 제외하고 '해당 없음'으로 집계한다.기한 없음—부문장 + HRD 책임자
R-10유예기한만 연장한다. 분모에는 남기고 '유예' 상태로 집계한다. 사유·유예기간·승인자를 기록한다.승인된 연장일—팀장 + HRD 담당
R-11자격 만료 · 갱신만료 90일 전에 갱신 과정을 자동 배정한다. 법정 선임 자격은 만료 시 선임 공백 알림을 즉시 발생시킨다.자격 만료일갱신 전 자격은 만료일까지 유효자동 + 안전환경 책임자
R-12휴직 · 복직 · 퇴직휴직 기간만큼 기한을 자동 연장하고 복직일 기준으로 재계산한다. 퇴직 시 미이수 배정은 '해당 없음'으로 종료한다.복직일 + 잔여일수휴직 전 수료 유지자동
R-13교육규칙 개정새 규칙 버전은 적용일 이후 배정에만 적용한다. 과거 배정의 근거·기한·결과는 덮어쓰지 않고 보존한다.개정 전 배정은 기존 기한 유지—HRD 책임자
R-14결측값 처리'해당 없음'(적용 대상 아님)과 '미확인'(데이터 없음)을 구분한다. 미확인은 분자·분모 모두에서 제외하고 별도 집계한다.——자동

배정 의사코드

FUNCTION 배정(직원 e, 기준일 d, 규칙버전 v):
  대상 ← []
  FOR 각 담당직무 j IN e.직무목록:              // R-03 겸직 = 복수 직무 합집합
    FOR 각 과정 c IN 교육과정(j, e.숙련수준, e.직책):
      IF 유효배정_존재(e, c):        CONTINUE      // R-08 중복 배정 방지
      IF 면제승인(e, c):             상태 ← 해당없음  CONTINUE   // R-09 분모 제외
      IF 동등과정_수료(e, c) OR 외부자격_유효(e, c):
                                        상태 ← 인정      CONTINUE   // R-06
      IF 기존수료(e, c) AND 경과일(e, c) ≤ c.인정기간:
                                        상태 ← 수료인정  CONTINUE   // R-07
      IF c.선수과정 AND NOT 수료(e, c.선수과정):
                                        상태 ← 대기      CONTINUE   // R-05

      기한 ← 기산일(e, c) + c.기한일수                    // R-01 / R-02 / R-04
      IF e.휴직중:  기한 ← 기한 + e.휴직일수                 // R-12
      IF 유예승인(e, c): 기한 ← 승인된_연장일                // R-10
      대상 += 배정{직원 e, 과정 c, 기한, 규칙버전 v, 생성일 d, 근거}
  RETURN 대상

FUNCTION 갱신점검(직원 e, 기준일 d):                        // R-11
  FOR 각 자격 q IN e.자격목록:
    IF q.만료일 - d ≤ 90일:  배정(갱신과정(q), 기한 = q.만료일)
    IF q.법정선임 AND q.만료일 < d:  알림(선임 공백, 즉시)

FUNCTION 규칙개정(신규버전 v2, 적용일 t):                   // R-13

  t 이후 신규 배정에만 v2 적용

직무체계

직무구분Job Classification
회사의 여러 일을 성격이 비슷한 것끼리 묶는 큰 틀. 이 도구의 Level 1이며 9개 직군이 여기에 해당합니다.
직군Job Family
직무구분과 같은 층위에서 쓰는 말. 대분류 단위의 직무 묶음입니다.
직무정의Job Definition
그 직무가 왜 존재하고 무엇을 하는지 한두 문장으로 요약한 목적. Level 2입니다.
직무기술서JD · Job Description
직무를 맡은 사람이 실제로 해야 하는 업무 내용과 책임을 적은 문서. 일 중심입니다.
직무명세서JS · Job Specification
그 일을 해내기 위해 사람에게 요구되는 지식·기술·자격을 적은 문서. 사람 중심입니다.
숙련수준
실제 수행능력 단계(L1~L5). 회사의 인사 등급인 직급, 관리 책임인 직책, 조직 단위인 부서와는 모두 별개의 축입니다.
근거등급
정보의 출처 신뢰도. 확인 사실(공식 자료에서 직접 확인) · 설계 추론(사업 특성에서 도출) · 사내 확인 필요 · 가상 예시로 구분합니다.

역량 · 교육

NCSNational Competency Standards
국가직무능력표준. 산업 현장의 직무 수행에 필요한 능력을 국가가 표준화한 체계로, 대분류 24개에서 세분류까지 내려갑니다.
능력단위
NCS 세분류를 구성하는 교육·평가의 최소 단위. 분류번호와 수준(1~8)을 가집니다.
수행준거

K·S·AKnowledge, Skill, Attitude
필요지식 · 필요기술 · 직무수행태도. 직무명세서의 핵심 구성 요소입니다.
HRD / L&DHuman Resource Development / Learning & Development
인재 개발과 교육 훈련 기능. 직무기술서를 교육 요구조사 결과로 활용합니다.
CDPCareer Development Path
경력 개발 경로. 상위 레벨 직무로 성장하는 단계와 필요 교육을 설계합니다.
OJTOn-the-Job Training
현업에서 지도자를 두고 수행하는 실무 훈련. 독립수행 승인의 선행 단계입니다.
SMESubject Matter Expert
직무 전문가. 직무 문서와 NCS 매핑의 내용 타당성을 검토·승인합니다.
ADDIE
교육과정 설계 모형. 분석 · 설계 · 개발 · 운영 · 평가의 5단계입니다.
